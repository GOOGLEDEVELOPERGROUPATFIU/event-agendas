# Participant Information

Welcome to **Build with Gemma: 305 HackFiesta Miami Edition**.

During this hackathon, participants will build creative AI projects using Google DeepMind's open Gemma models.

Your goal is to create a working prototype that solves a real problem or improves an existing experience using Gemma.

Projects can include:

* Kaggle Notebooks
* Developer tools
* AI assistants
* Multimodal applications
* AI agents
* On-device AI applications
* Experimental AI prototypes

Participants may build projects in areas such as:

---

# Submission Requirements

Each team must submit the following:

## 1. Kaggle Writeup

Explain:

* Project overview
* Problem being addressed
* Proposed solution
* Technical architecture
* How Gemma was used
* Challenges encountered
* Final results and what was built

## 2. Working Demo

Submit at least one way for judges to experience or review your project.

Examples include:

* Live application URL
* Video demo
* Kaggle Notebook
* Hosted application
* Terminal recording
* Demo files

## 3. Public Code Repository

Submit a public:

* GitHub repository
* Kaggle Notebook
* Other publicly accessible code repository

The code should be organized and documented clearly enough for judges to understand how Gemma was integrated into the project.

---

# Judging Criteria

Projects will be evaluated out of **100 points**.

## Gemma Integration — 30 Points

How effectively does the project use Gemma?

Is Gemma a meaningful and important part of the solution?

## Innovation & Impact — 30 Points

Does the project solve a meaningful problem?

Is the idea creative, useful, or innovative?

## Functionality — 20 Points

Does the prototype work?

Does the demonstration effectively show the project's functionality?

## Presentation & Writeup — 20 Points

Does the team clearly communicate:

* The problem
* The solution
* The technical approach
* How Gemma was used
* What was accomplished

# Rules

* Participants must use Gemma in their project.
* Teams must submit their projects before the applicable deadline.
* Projects must be original work developed during the hackathon period.
* Participants may use open-source libraries, APIs, starter code, and AI development tools.
* Teams must disclose and explain major tools, APIs, models, and external resources used.
* All submissions must follow the hackathon Code of Conduct.
* Empty submissions, spam, copied projects, or projects that do not meaningfully use Gemma may be disqualified.
* Organizers reserve the right to review submissions for eligibility before judging.
